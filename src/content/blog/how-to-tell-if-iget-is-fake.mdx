## Check 1: Verify the orange code on the box

IGET's current boxes carry an orange anti-counterfeit code, which IGET calls the Orange Code or Earth Code, on the bottom of the packaging. It's the check IGET itself tells customers to use, and it takes about a minute:

1. Turn the box over and find the orange code.
2. Open IGET's verification page, [igetvape.com/ProductVerificate.html](https://www.igetvape.com/ProductVerificate.html), on your phone.
3. Under **New Code Verification**, choose **Take A Picture To Verify** and photograph the code.
4. Wait for the result before you open or use the vape. A sealed box is easier to send back.

IGET says every genuine product has "a unique official anti-counterfeit code", so the code belongs to that one box.

## Check 2: Older boxes have a QR code instead

Boxes made before the orange code have a **green QR code** and an **18-digit anti-counterfeit number**. On the same page, under **Old Code Verification**, scan the QR code or type in the number. Two things to watch:

- **Where the QR code takes you.** A genuine code opens IGET's verification page on igetvape.com. IGET's advice is that if scanning doesn't take you to the official page, the product may be counterfeit. Read the address bar, not just the look of the page.
- **What the result says.** IGET's check gives one of three answers:

| The page says | What it means |
| --- | --- |
| "This product is genuine." | The code is real. |
| "This anti-code was checked over 3 times, it's a fake" | IGET treats the box as counterfeit, most likely because the same code has been copied onto other boxes. The message asks you to email iget@igetvape.com to double-check. |
| "This QR code is not exist" or "The security code is invalid" | The code isn't in IGET's records. Treat it as fake. |

**No QR code on your box?** That's not a sign of a fake. In September 2026 IGET announced that its new packaging drops the QR code and keeps only the orange code, and that old and new boxes will be on sale side by side. Both are genuine.

## Check 5: The small print on the box

IGET's April 2026 warning put a genuine box beside a counterfeit one. The fake was missing the orange anti-counterfeit code and the traceability code, and it had the wrong certification mark and icons IGET doesn't use. So compare your box with the photos on IGET's model page, looking at:

- the orange code, or on an older box the QR code and 18-digit number
- the traceability code
- the certification marks and icons

IGET's own box photos also show the maker's name, Shenzhen Hua Xinyu Technology Co., Ltd., and www.igetvape.com printed on the packaging.

What this list leaves out: price, taste and weight. Plenty of sites claim a fake tastes burnt or feels light, but IGET doesn't say so, and a genuine vape tastes burnt too once its liquid runs low (see [signs a pod is finished](/blog/how-long-does-an-iget-bar-plus-last)). The code is far more reliable than your taste buds.

## Why a fake is worth avoiding

IGET says counterfeits "have not undergone any official quality testing or safety certification". The label on a fake can't be trusted either: NSW Health reports that lab testing of seized vapes has shown "even vapes labelled 'nicotine-free' can have high nicotine levels" ([NSW Health](https://www.health.nsw.gov.au/tobacco/Pages/e-cigarettes.aspx)). A box that copies IGET's design tells you nothing reliable about what's inside it.
